# 共用逐篇录入流程

从刚交付的清单续录高赞视频时，按账号用已核实点赞各选指定数量，这时再确认入选作品是视频。只补会影响排名的字段；不能确认全量名次就报缺口并注明实际选集。

同篇完整字幕或可信本地媒体直接续做。网页取源校验后立即落盘，一条就绪即启动 `prepare`，同时取下一条的源。同批只开一个本地转写任务，草稿就绪即校对，再 `finalize` 和回读。失败仅续当前项。

## 来源清单状态回写

仅本次明确从某份 Markdown 清单选作录入时才回写该清单（独立链接不触发）：

```sh
"$PYTHON" "$SKILL_DIR/scripts/source_list.py" init "$SOURCE_LIST"
"$PYTHON" "$SKILL_DIR/scripts/source_list.py" mark "$SOURCE_LIST" --manifest "$SAVED_MANIFEST"
"$PYTHON" "$SKILL_DIR/scripts/source_list.py" mark "$SOURCE_LIST" --verified-note "$COMPLETE_NOTE"
```

保存回读成功（`saved`）或既有完整稿核验无误后标「已录入」；失败、`prepared`、`no_speech` 或缺口待核留空。

## 视频与图文处理校对

- **图文与无口播视频**：抖音／小红书图文取正文及必要图序 OCR（遮挡不猜，保留必要 `【图N】`）；`status="no_speech"` 的纯配乐画面视频按可见画面原字录入并注明“无口播”，不凭空脑补。
- **视频口播校对五步**（`large-v3-turbo` 默认产出无时间戳 `draft.txt`，完整时间轴留存 `asr.json`）：
  1. **通读草稿与多人补跑**：结合同篇已取得的标题／文案（`raw_title`／`text`）核对专名、人名、书展名与品牌词，校同音字、数字与否定，并将转写偶发混出的繁体字统一为简体；保留原话内容、顺序与有意义重复，**严禁摘要、删段或用省略号替代原话**。读稿发现问答交替时调 `<平台脚本> diarize --manifest <manifest.json>` 秒级补分说话人；若 `draft_quality` 报乱码或死循环，核原音频后最多调一次 `recover --manifest`。
  2. **空档核实与局部补转（宁缺毋滥）**：遇草稿含 `【未覆盖 X–Ys】`（片头／片尾 ≥10 秒或中段 ≥8 秒无字空档），或上下文无法判断的关键专名／数字错漏，调 `retry-excerpt --manifest <manifest.json> --clip <起秒> <止秒>` 复核（同一窗口一次）。确属纯配乐／停顿则删去标记（未跑补转而已从播放器确认纯静音时，在 `finalize` 加 `--verified-silence` 登记放行）；确有口播则补回；局部复转仍不通顺或有专名疑点时，查看同一时间点的原视频画面字幕（如 `ffmpeg` 截帧），有清晰字幕即据此校词，剩余个别疑词标“（此处转写存疑）”后正常保存；**若补转与核对字幕后仍大段坏音缺失无法恢复，严禁带缺口写入正式库，保留现场并在报告单列**。
  3. **标点与自然分段**：补齐中文标点，保留英文、网址、代码与小数；按话题与论点自然分段（长稿按 2000–3000 字语义块带上下文校对）。
  4. **硬门禁落盘**：`reviewed.txt` 仅写纯校对正文（不含 YAML Frontmatter）；`finalize` / `save-note` 自动拦截残留空档或缺失占位符、长空档未核实删标、全角 `Ｂ`／替换符／单字符刷屏／连续重复循环、300 字以上长稿超 900 字大段或超 220 字无句末标点、相对去重草稿低于 78% 的疑似删段稿及未净尾缀标题。
  5. **成稿回读**：打开已保存 Markdown 核对首尾、分段与七字段无误；若回读发现漏校字词，先改 `reviewed.txt` 再重跑 `finalize`（同一任务未被动过时自动原地更新），勿绕过校对稿直接手改交付成稿。

## 文章正文：公众号与知乎共用

按“定位本篇 → 获取全文 → 核对正文 → 整理属性标签 → 保存回读”推进：
1. **定位与获取**：公众号用确定性解析器（见[公众号](weixin.md)）；知乎进入具体回答／文章直链（不用问题页 URL 冒充）展开全文并排除问题描述、其他回答与评论，必要文字图 OCR 去重叠，非文字图原位标 `[此处原文有图片]`。
2. **核对与落盘**：保原文字词、数字、标点、列表、段落顺序和个人署名，只修采集／OCR 错漏，不润色或加小标题。公众号作者填公众号名并保持解析散列；知乎通过 `media_common.py save-note` 统一落盘校验。
