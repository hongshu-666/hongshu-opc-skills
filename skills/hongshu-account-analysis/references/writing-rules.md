# 写作与排版规则

章节、表头与列序以[报告模板](../assets/account-analysis-template.md)为准，本文只补充写法和排版；采集、统计、溯源及附件操作按主流程执行。这些说明不进入成品。

## 通用写法

- 直接写结论，用短句、短产品名和短人群描述；未知写“暂无”。不堆过程词、括号、版本解释或检索记录。
- 结论放对应单元格，表后不另加总结或核验说明。影响结论的限制在同格简写一句，其余留研究依据。概括不用引号装成原话。
- 开头摘要用原生无序列表，不手打圆点；核心判断不凑条数。产品名称、作品和反馈可保留出处链接，不增加模板外的板块或过程字段。

## 1. 账号信息

### 1.1 基础信息

表头和左列居中，右列左对齐。账号信息用飞书原生无序列表，简介原文逐行嵌套，忠实保留；主页放可点击链接。认证或必要行动入口补入同格，置顶在作品清单标记。

### 1.2 作品清单

飞书用内嵌原生电子表格；Markdown表仅表示数据结构。表头与数据均为11号字，水平、垂直居中，标题换行；1.2、1.3标题用实际作品数量。

默认按点赞降序整行排序并重编展示序号，原ID映射留研究依据；点赞不可靠则保留主页顺序。保留点赞原有精度和页面可知日期，区分发布、编辑、整理日期，不从文件名反推年份。链接可显示“查看作品”，不加“未核实”或“录入状态”。

### 1.3 作品分析

“流量最好”按可得且可比的数据判断；只有点赞时明确写点赞中位数，不冒充播放量，无可靠数据则省略。该行用浅绿色底色，“讲得最多”用浅红色；下表表头与内容居中，对应主题名称标同色底。

主题直说“在讲什么”，用具体话题，不把“同行共鸣”等作用或形式当主题，不套行业标签。只比较已明确的主题，不把少讲认定为市场空白。

### 1.4 完整内容分析

按模板填视频稿、图文稿和独立作品总数，每篇一行；表头居中，附件列左对齐，其余列居中，全部垂直居中。图文全文也作为Markdown附件放第一列。

按全文重心选一个主要类型，内容作用另写一句具体作用：

| 内容类型 | 判断重心 |
| --- | --- |
| 观点型内容 | 行业看法、价值判断、专业立场 |
| 教学型内容 | 方法、步骤、操作与判断思路 |
| 案例型内容 | 具体客户或学员的问题、经历、变化与结果 |
| 经历型内容 | 作者自身经历、取舍和过程 |
| 产品型内容 | 产品、课程、服务、安排或交付体验 |

学员案例一般归案例型；课堂教知识归教学型，展示课程与体验归产品型。末尾招生不自动改变主要类型。“转化、建立信任、吸引关注”是作用；无扩散或跨人群证据，不硬写“已破圈”。

## 2. 产品分析

每个可区分的产品一行，名称简短且能对应资料；混合业务按性质分组。主推无依据写“暂无”。课程按模板只写教学时间、培训内容，不加教学方式；有逐日日程才按天分段，不同期确有差异可简写“不同期安排不同，例如……”。

价格字段只写普通数字和单位，如“9800元”“1980元／人／期”，不加千位逗号、金额链接或来源年份等括号说明。优先对应产品的最新可靠价；用户接受时可用历史参考，来源、年份、适用期次和不确定性留研究依据，必要时在交付说明，不宣称是当前官方价。学费、定金、模块价、个人总开销分开；问价假设不当收费事实，标题线索不当明确报价。

非课程产品把课程名称、教学时间／培训内容、开班／人数，分别改为产品名称、交付周期／服务内容、发售或预约／名额，按真实服务填，不强套班型。人数只填实际服务容量，不填累计购买人数；各字段未知写暂无。费用包含项、复修条件只按明确资料写；授课时间、全流程工时和课后指导分清，完整大纲不冒充逐日日程。

## 3. 用户反馈

只写实际使用或上课后的认可、不满与局限；询价、“私我”等咨询不进评价表。优先个人体验，机构访谈和账号选发聊天也可保留，来源属性分清，同一反馈跨帖不重复计证据。

来源列写发布者、亲历或机构发布属性、对应产品和原链接，日期有助区分版本时保留。亲历、付费、赠送、合作、报名状态及所评服务只按明确证据记录。评价可有好有坏，不凑正负对称；少量评价不代表全体客户。

无可用反馈时写“暂无可用的亲身体验或评价”，省略空表，继续其余部分；未找到不等于没有差评或隐藏收费。

## 4. 人群分析

优先按学习或购买目的区分，不把同一需求的熟手、新手机械分组。按内容和产品证据排序，不假称营收或学员占比；第二人群无依据则省略。核心需求尽量压成三条，末列只写对应产品名称与用途。

产品匹配兼看公开定位和实际体验，不由有人报名推断适合所有同类人。自填年龄可注明来源，不作硬性门槛；当前对象与未来愿望按主流程区分。

## 5. 人设分析

用模板的两列四行普通文档表格，无表头，不拆小节。身份一句话概括，机构兼看创始人、团队和机构；观点提炼最多三条稳定主张。表达风格从持续内容和互动提炼，不把本人期望当实际表达；信任依据分清自我背书、能力展示和外部体验。

不重抄简介、人群清单或产品安排；资历与效果的证据边界按主流程执行。
