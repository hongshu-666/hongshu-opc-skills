# 备忘录与长文
`TextLayout`保原段、自然换行；仅指定分行才设`user_requested_line_breaks`及字符偏移。标题语义1–2行。`备忘录`为苹果原生纯白无衬线风格（内置顶部悬浮胶囊栏、首页居中时间`memo_date`默认北京时间/空串关闭、粗体大标题、银灰竖杠小标题）；`长文`为暖米纸衬线正文配刊头与斜体编号，仅真实并列项编号。
备忘录按连续截屏式排满底线（章题带至少1行后文，避切断框选或4字内短尾，页尾劈词仅在同段内至多回退1–2行停标点，严禁跨段回退留大片空白）；长文逐行排满并避页首短孤行，段落/编号可跨页，末页均不均分（余文较短自动附`END`印记），不用整段分组替代分页器。备忘录改题重排；标题过小先商议，不擅缩写。
重点摘原句：备忘录每页至多1处苹果原生浅黄框选（优先页内1–2行核心金句，不整段铺黄）；长文每个正文页适度半高暖香槟荧光条，不作重点加粗；章题/段落层级按内容使用。看预览图时逐页自检：长文确保每个正文页至少1处荧光条、备忘录每页至多1处且不跨页切断，漏标/误加粗立即补齐重出预览后再交用户确认。
长文封面默认自动放大标题撑开版心，按指定层级可设`cover_title_sizes`逐行正整数字号（超版心报错）；`cover_title_offset_y`整数像素默认0（负上正下，眉线与主副题整体平移，不进照片或页脚）。`cover_subtitle`省略沿用`personal.json`固定副题（未配留空），明确要求才替换或传空串关闭，不自拟。只改封面可用`reuse_body`配原`reuse_record`；正文/品牌/页码变须重排。

## 最小 `spec.json` 字段速查（免翻源码）
```json
{
  "mode": "长文", "theme": "主题短名", "version": "初稿01",
  "title": "完整标题", "publish_title": "完整标题", "title_lines": ["首行语义", "次行语义"],
  "source_text": "段1原句金句\n\n段2", "publish_copy": "≤1000字发布文案", "paragraph_separator": "\n\n",
  "blocks": [{"text": "段1原句金句", "marks": ["原句金句"]}, {"text": "段2", "heading": false}],
  "gallery_request": "/输出目录路径:1"
}
```
> 备忘录省去`gallery_request`（可选`memo_date`）；无图库指定单照改传`"user_selected_photo": true, "cover": "/照片路径"`；原文已带「第一/第一种」编号勿叠`"number": 1`。
